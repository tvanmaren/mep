# Example Profiles

Profiles describe repo-specific semantics: reducers, zones, smoke tests, and review surfaces.

These files are examples bundled with the tool. They are not the active profile for an arbitrary repo.
An active repo profile should live under the configured `profile.dir`, usually `.mep/profiles`.

`example-stub.md` is the portable skeleton. A host may keep its own named profile privately; that is
not shipped here.
